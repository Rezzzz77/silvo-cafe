# ☕ کافه سیلو پلازا — اپلیکیشن سفارش و پرداخت (نسخه اجرایی)

پروژه بازسازی‌شده از جلسه «پروژه مخصوص کافه رستوران‌ها» — این نسخه **واقعاً اجرا می‌شود**.

## اجرای سریع

```bash
# ۱) بک‌اند (پورت 4000)
cd backend && node server.js

# ۲) فرانت‌اند (Expo — پورت 8081)
cd frontend && npx expo start

# در گوشی: اپ Expo Go را باز کنید و exp://localhost:8081 را اجرا کنید
```

## اتصال به سرویس‌های واقعی (اختیاری)

بدون تنظیمات، همه‌چیز در **حالت دمو** کار می‌کند. برای فعال‌سازی نسخه واقعی:

```bash
# درگاه پرداخت زرین‌پال (از panel.zarinpal.com مرچنت کد بگیرید)
export ZARINPAL_MERCHANT_ID="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

# پیامک کاوه‌نگار (از kavenegar.com کلید API بگیرید)
export KAVENEGAR_API_KEY="YourApiKey"
export KAVENEGAR_SENDER="10004346"

node server.js
```

- **درگاه**: با مرچنت کد، جریان واقعی زرین‌پال فعال می‌شود (request → درگاه → verify در سرور طبق قانون شاپرک)
- **پیامک**: با کلید کاوه‌نگار، ارسال واقعی؛ بدون کلید، شبیه‌سازی

## API بک‌اند

- `POST /api/auth/login` — ورود/ثبت‌نام با نام + موبایل
- `GET  /api/cafes` / `GET /api/cafes/:id` — کافه‌ها و منو
- `GET  /api/cafes/:id/tables` — وضعیت میزها
- `POST /api/orders` — ثبت سفارش روی میز
- `POST /api/orders/:id/pay` — پرداخت (شبیه‌سازی + تخفیف تولد/امتیاز)
- `GET  /api/admin/tables` + `POST /api/admin/orders/:id/status` — پنل مدیریت
- `POST /api/spin` + `GET /api/profile/:id` — وفاداری

## نکته برای ارائه به مدیر کافه

برای دموی زنده، دو سناریو را کنار هم نشان دهید:
1. **گوشی مشتری**: انتخاب میز → ورود → منو → سبد → پرداخت → پیگیری وضعیت
2. **همان گوشی یا گوشی مدیر**: پنل مدیریت → سفارش جدید را تایید و مرحله‌به‌مرحله جلو ببرید — مشتری زنده می‌بیند.
